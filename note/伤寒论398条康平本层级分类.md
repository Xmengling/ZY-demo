# 《伤寒论》398条康平本排版层级分类

## 口径

- 顶格＝一级；降一格＝二级；降二格＝三级。
- 归类对象是宋本第1—398条对应的康平本条文正文；方剂组成和方后注的缩进不计入条文层级。
- 同一宋本条号内若包含两种排版，保留为“混合层级”，不强行压成单一等级。
- 版式归类与作者归属、学术价值不是同一个概念；这里记录的是康平本排版事实，并附李冠杰老师的校勘判断。

## 统计

- 单一顶格：162 条
- 单一降一格：85 条
- 单一降二格：138 条
- 混合层级：13 条
- 按“包含该层级”统计：顶格 173 条、降一格 98 条、降二格 140 条。

## 混合层级

- 第6条：顶格 + 降一格。条内多段，顶格与降一格交替排版。
- 第16条：顶格 + 降一格。主体为顶格；“桂枝本为解肌……”一段为降一格。
- 第93条：顶格 + 降一格。顶格正文后接降一格补充。
- 第98条：降一格 + 顶格。先为降一格，转行后变为顶格；李冠杰认为排版存在传抄错误，不宜硬判为单一层级。
- 第105条：顶格 + 降一格。同一宋本条号内含顶格正文与降一格补充。
- 第120条：顶格 + 降一格。同一宋本条号内含顶格正文与降一格补充。
- 第140条：顶格 + 降一格。顶格残文与降一格补充并存。
- 第141条：顶格 + 降一格。“病在阳……”正文为顶格；“身热、皮粟不解……”为降一格。白散方另为降二格，但方剂版式不计入条文层级。
- 第208条：顶格 + 降一格。“阳明病……”至“大承气汤主之”为顶格；“若汗出多……”为降一格。
- 第209条：顶格 + 降一格。前一自然段为顶格，后一自然段为降一格。
- 第214条：降一格 + 降二格。“小承气汤主之”以前为降一格，之后为降二格。
- 第316条：降一格 + 顶格。正文为降一格；末尾“武汤主之”转行后误排成顶格，李冠杰明确判断为传抄笔误。
- 第366条：降二格 + 降一格。“下利，脉沉而迟……”为降二格；“病人必微厥……”为降一格。

## 康平本实排与李冠杰校勘判断不同的重点

- 第391条：康平本版式为顶格；李冠杰从语韵和内容判断，怀疑原本可能是降二格。
- 第394条：康平本两个自然段均为顶格；李冠杰认为“脉浮者……”以下第二段可能原为降二格。
